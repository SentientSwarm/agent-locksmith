# Archive

These documents record earlier designs, plans and specifications. They do
not describe current behaviour; start at the [documentation index](../README.md).
They are kept because source comments and tests cite their task tags
(`T6.5`, `INF-3`, `D-10` and similar). Paths inside them are as written at
the time; many files have since moved.
